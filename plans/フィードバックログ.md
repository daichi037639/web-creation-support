# フィードバックログ

サービスを実際に使って気づいたこと・改善したいことをメモする場所。
気軽に書き留めておき、実装の優先順位決めに使う。

---

## 書き方

```
## YYYY-MM-DD

**良かった点**
- 

**気になった点・改善したい点**
- 

**アイデア**
- 
```

---

## 2026-06-28

**気になった点・改善したい点**
- サービスの形態（オンライン販売 / 実店舗など）や業界を選ぶ場所がほしい
- 形態・業界によって入力項目を変えたほうがいいかも（例：飲食店に「顧客の悩みや不満」は不自然）
- 各入力項目の必須 / 任意を区別・明示したい

**アイデア**
- 選択した業界・形態に応じて類似サイトを調査し、サイト制作の参考にする
- 業界別の「要件定義の型」や「良いサイトの例」をAIの裏側のプロンプトに組み込んで精度を上げる
